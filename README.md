# Finance-Buddy

A web app built with **Angular** and **.NET Core** to track and manage expenses. Features include user authentication, expense categorization, budget tracking, and reports with analytics. Uses **JWT authentication**, **Entity Framework**, and **SQL Server**. Optimized for all devices. 🚀  

## Tech Stack  
- **Frontend:** Angular, TypeScript  
- **Backend:** .NET Core, Entity Framework, SQL Server  

## Features  
✔ User Authentication  
✔ Expense Tracking  
✔ Budget Management  
✔ Reports & Analytics
