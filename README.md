# Finance-Buddy
Expense Manager
A web application built with Angular (frontend) and .NET Core (backend) to efficiently track and manage personal or business expenses. The application allows users to categorize expenses, set budgets, generate reports, and visualize spending patterns.

🚀 Features:
User Authentication (Login/Register)
Expense Tracking (Add, Edit, Delete transactions)
Categories & Budgets (Set limits for expense categories)
Reports & Analytics (Charts & insights on spending habits)
Multi-Currency Support (Optional)
Responsive UI (Optimized for all devices)
🛠️ Tech Stack:
Frontend: Angular, TypeScript, Bootstrap
Backend: .NET Core, Entity Framework, SQL Server
Authentication: JWT Authentication
Deployment: Azure / Docker (Optional)
📌 Setup Instructions:
Clone the repository
Install dependencies (npm install for Angular, .NET restore for backend)
Configure database connection
Run frontend and backend servers
This project aims to provide an intuitive way to manage and monitor expenses, helping users stay financially organized. 🚀
